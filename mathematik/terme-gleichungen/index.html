Terme vereinfachen und Gleichungen lösen

Zwei typische Gymi-Aufgaben: einen Term mit x so weit wie möglich vereinfachen und eine Gleichung lösen, mit der Lösung als Dezimalbruch.

Grundbegriffe

Ein Term ist ein Rechenausdruck mit Zahlen und Buchstaben. Der Buchstabe (meist x) heisst Variable und steht für eine unbekannte Zahl.

Begriff Bedeutung Beispiel
Variable Platzhalter für eine Zahl x, a, b
Koeffizient die Zahl vor der Variablen bei 4x³ ist es 4
Potenz eine Zahl mehrmals mit sich selbst malgenommen x · x = x², x · x · x = x³
Exponent die kleine hochgestellte Zahl: wie oft man malnimmt bei x³ ist es 3
gleichartige Terme Terme mit genau der gleichen Variablen und dem gleichen Exponenten 4x³ und −x³ sind gleichartig, x² und x³ nicht
Gleichung zwei Terme mit einem = dazwischen 5x − 12 = 27

Unsichtbare Zahlen: x bedeutet 1 · x, und x bedeutet auch x¹. Ein Minus vor x bedeutet −1 · x. Das braucht man beim Zusammenzählen oft.

Terme vereinfachen

«So weit wie möglich vereinfachen» heisst: am Schluss steht jede Potenz von x höchstens einmal da. Dafür gibt es vier Schritte.

  1. Malpunkte zu Potenzen machen: x · x = x², x · x · x = x³. Zahlen davor bleiben stehen: 5x · x = 5x².
  2. Gleichartige Terme erkennen: Nur Terme mit gleicher Variable und gleichem Exponenten gehören zusammen (x³ mit x³, x² mit x²).
  3. Ordnen: Gleichartige nebeneinander schreiben, der höchste Exponent zuerst. Das Vorzeichen geht mit dem Term mit.
  4. Zusammenfassen: Nur die Koeffizienten (Zahlen davor) addieren oder subtrahieren. Der Teil mit x bleibt gleich.

Prüfungsaufgabe a)

Vereinfache: x² + 4x³ + 5x · x − x · x · x

Schritt Rechnung
1. Potenzen x² + 4x³ + 5x² − x³
2./3. Ordnen 4x³ − x³ + x² + 5x²
4. Zusammenfassen (4 − 1)x³ + (1 + 5)x²
Resultat 3x³ + 6x²

Probe mit einer Zahl: Setze x = 2 in die Aufgabe und ins Resultat ein. Aufgabe: 4 + 32 + 20 − 8 = 48. Resultat: 3 · 8 + 6 · 4 = 24 + 24 = 48. Gleich, also stimmt es.

Typische Fehler

Die meisten Fehler entstehen, weil man Addieren und Malnehmen verwechselt.

Falsch Richtig Warum
x · x = 2x x · x = x² malnehmen gibt eine Potenz, nicht das Doppelte
x + x = x² x + x = 2x zwei gleiche Dinge zusammenzählen gibt das Doppelte
x² + x³ = x⁵ x² + x³ bleibt x² + x³ nicht gleichartig: kann man nicht zusammenfassen
4x³ − x³ = 4 4x³ − x³ = 3x³ −x³ heisst −1 · x³; der Teil x³ bleibt stehen
3x · 2x = 5x² 3x · 2x = 6x² Zahlen malnehmen (3 · 2), x · x = x²
x² · x³ = x⁶ x² · x³ = x⁵ (x · x) · (x · x · x) sind 5 Faktoren: Exponenten addieren
2x² + 3x = 5x³ bleibt 2x² + 3x x² und x sind nicht gleichartig

Merke: Beim Plus/Minus ändert sich der Exponent nie. Nur beim Malnehmen werden aus x und x zusammen x².

Gleichungen lösen

Ziel: x steht am Schluss allein auf einer Seite. Dafür macht man Rechenschritte rückgängig, und zwar immer auf beiden Seiten gleich (Waage-Prinzip).

steht da … rückgängig machen mit …
− 12 + 12
+ 7 − 7
5 · x (5x) : 5
x : 4 · 4

Reihenfolge: Zuerst die Zahl ohne x wegschaffen (Plus/Minus), dann den Koeffizienten vor x (Mal/Geteilt).

Prüfungsaufgabe b)

Bestimme die Lösung der Gleichung 5x − 12 = 27 als Dezimalbruch.

  1. 5x − 12 = 27  | + 12
  2. 5x = 39  | : 5
  3. x = 39 : 5 = 7,8

«Als Dezimalbruch» heisst: nicht 39/5 oder 7⅘ hinschreiben, sondern als Dezimalzahl 7,8.

Trick für «: 5»: Durch 5 teilen ist dasselbe wie mal 2 und dann durch 10: 39 · 2 = 78, 78 : 10 = 7,8.

Weitere Beispiele: Gleichungen

Von einfach bis knifflig. Die Spalte «Besonderes» zeigt, worauf man aufpassen muss.

Nr. Gleichung Schritte Lösung Besonderes
1 x + 7 = 15 − 7 x = 8 nur ein Schritt
2 3x = 21 : 3 x = 7 nur ein Schritt
3 4x + 5 = 25 − 5 → 4x = 20, : 4 x = 5 ganze Zahl
4 2x − 9 = 4 + 9 → 2x = 13, : 2 x = 6,5 Dezimalbruch
5 8x − 3 = 3 + 3 → 8x = 6, : 8 x = 0,75 Lösung kleiner als 1
6 4x + 3 = 1 − 3 → 4x = −2, : 4 x = −0,5 negative Lösung
7 7 − 2x = 1 − 7 → −2x = −6, : (−2) x = 3 Minus vor x: durch die negative Zahl teilen
8 3x + 4 = x + 14 − x → 2x + 4 = 14, − 4 → 2x = 10, : 2 x = 5 x auf beiden Seiten: zuerst x auf eine Seite bringen
9 x : 4 + 3 = 5 − 3 → x : 4 = 2, · 4 x = 8 geteilt rückgängig mit mal
10 2(x + 3) = 15 Klammer: 2x + 6 = 15, − 6 → 2x = 9, : 2 x = 4,5 zuerst Klammer auflösen
11 6x − 2,5 = 0,5 + 2,5 → 6x = 3, : 6 x = 0,5 Dezimalzahlen in der Gleichung
12 5x + 2x − 3 = 11 zusammenfassen: 7x − 3 = 11, + 3 → 7x = 14, : 7 x = 2 zuerst vereinfachen (wie bei Aufgabe a)

Bruch in Dezimalbruch umwandeln

Wenn am Schluss eine Division nicht aufgeht, so umrechnen:

  • : 2 → 13 : 2 = 6,5 (die Hälfte)
  • : 4 → 18 : 4 = 4,5 (zweimal halbieren)
  • : 5 → 39 : 5 = 7,8 (mal 2, dann durch 10)
  • : 8 → 6 : 8 = 0,75 (dreimal halbieren)
  • : 10 → Komma eine Stelle nach links

Geht die Division nie auf (z. B. 10 : 3 = 3,333…), ist das Resultat eine periodische Dezimalzahl: 3,3.

Anspruchsvolle Beispiele: Terme

Diese Aufgaben kombinieren mehrere Schwierigkeiten: Zahlen und Potenzen im gleichen Produkt, Klammern und Minuszeichen. Langsam Schritt für Schritt arbeiten.

Regeln für Klammern und Vorzeichen

  • Zahl vor der Klammer: mit jedem Term in der Klammer malnehmen: 2x(x + 3) = 2x² + 6x
  • Minus vor der Klammer: Klammer weglassen und alle Vorzeichen darin umdrehen: −(2x² − x³) = −2x² + x³
  • Minus mal Minus gibt Plus: −x · (−x) = +x²
  • Potenzen malnehmen: Exponenten addieren: x² · x = x³, 3x · 2x² = 6x³

K1: Zahlen und Potenzen gemischt

3x · 2x² − x³ + 4x · x − 2x² + x · x · x

  1. Produkte ausrechnen: 3x · 2x² = 6x³, 4x · x = 4x², x · x · x = x³
  2. Neu: 6x³ − x³ + 4x² − 2x² + x³
  3. x³-Terme: 6 − 1 + 1 = 6; x²-Terme: 4 − 2 = 2
  4. Resultat: 6x³ + 2x²

K2: Zwei Klammern, eine mit Minus davor

2x(x + 3) − x(x − 4)

  1. Erste Klammer: 2x · x + 2x · 3 = 2x² + 6x
  2. Zweite Klammer mit −x: −x · x − x · (−4) = −x² + 4x
  3. Zusammen: 2x² + 6x − x² + 4x
  4. Resultat: x² + 10x

K3: Minus vor der Klammer

x³ − (2x² − x³) + 3x · x

  1. Klammer auflösen, Vorzeichen umdrehen: x³ − 2x² + x³ + 3x²
  2. x³-Terme: 1 + 1 = 2; x²-Terme: −2 + 3 = 1
  3. Resultat: 2x³ + x²

K4: Minus mal Minus

−x · (−x) + x² − 2x · x · (−x)

  1. −x · (−x) = +x² (zwei Minus ergeben Plus)
  2. −2x · x · (−x) = +2x³ (wieder zwei Minus)
  3. Neu: x² + x² + 2x³
  4. Resultat: 2x³ + 2x²

K5: Höhere Potenz x⁴

(x · x) · 3x − 2x³ + x² · x · x

  1. x² · 3x = 3x³ und x² · x · x = x⁴
  2. Neu: 3x³ − 2x³ + x⁴
  3. Resultat: x⁴ + x³ (höchster Exponent zuerst)

K6: Zwei Variablen

4a · b · a − 3a²b + ab · a

  1. 4a · b · a = 4a²b und ab · a = a²b (die Reihenfolge beim Malnehmen spielt keine Rolle)
  2. Alle drei sind gleichartig (a²b): 4 − 3 + 1 = 2
  3. Resultat: 2a²b

K7: Alles fällt weg bis auf einen Term

5x² − 3x + 2 − (x² − 3x + 2)

  1. Minus vor der Klammer: 5x² − 3x + 2 − x² + 3x − 2
  2. x²: 5 − 1 = 4; x: −3 + 3 = 0; Zahlen: 2 − 2 = 0
  3. Resultat: 4x²

Anspruchsvolle Beispiele: Gleichungen

Fahrplan für schwierige Gleichungen: 1. Klammern auflösen → 2. jede Seite vereinfachen → 3. alle x auf eine Seite → 4. alle Zahlen auf die andere Seite → 5. durch die Zahl vor x teilen → 6. Probe.

G1: Zwei Klammern

3(2x − 1) − 2(x + 4) = 10

  1. Klammern: 6x − 3 − 2x − 8 = 10 (Achtung: −2 · 4 = −8)
  2. Vereinfachen: 4x − 11 = 10  | + 11
  3. 4x = 21  | : 4
  4. x = 5,25
  5. Probe: 3 · 9,5 − 2 · 9,25 = 28,5 − 18,5 = 10 ✓

G2: x auf beiden Seiten

7x − 4 = 3x + 9

  1. | − 3x → 4x − 4 = 9
  2. | + 4 → 4x = 13
  3. | : 4 → x = 3,25
  4. Probe: 7 · 3,25 − 4 = 18,75 und 3 · 3,25 + 9 = 18,75 ✓

G3: Minus vor der Klammer, x rechts

5 − 2(x − 3) = 4x

  1. Klammer: 5 − 2x + 6 = 4x (−2 · (−3) = +6)
  2. Vereinfachen: 11 − 2x = 4x  | + 2x
  3. 11 = 6x  | : 6
  4. x = 11 : 6 = 1,83 (periodischer Dezimalbruch, siehe Leitfaden Periodische Dezimalzahlen)

G4: Dezimalzahlen in der Gleichung

0,4x + 1,2 = 3

  1. Trick: alles mal 10, dann verschwinden die Kommas: 4x + 12 = 30
  2. | − 12 → 4x = 18
  3. | : 4 → x = 4,5

G5: x geteilt durch Zahlen

x : 2 + x : 4 = 4,5

  1. Trick: alles mal 4 (das kleinste gemeinsame Vielfache von 2 und 4): 2x + x = 18
  2. 3x = 18  | : 3
  3. x = 6
  4. Probe: 6 : 2 + 6 : 4 = 3 + 1,5 = 4,5 ✓

G6: Klammer auf einer Seite, Dezimalzahl auf der anderen

(x + 2) · 3 = 2x + 9,5

  1. Klammer: 3x + 6 = 2x + 9,5
  2. | − 2x → x + 6 = 9,5
  3. | − 6 → x = 3,5

G7: Textaufgabe «Denke dir eine Zahl»

Das Vierfache einer Zahl, vermindert um 3, ist gleich dem Doppelten der Zahl plus 6. Wie heisst die Zahl?

  1. Zahl = x. «Das Vierfache, vermindert um 3» = 4x − 3. «Das Doppelte plus 6» = 2x + 6
  2. Gleichung: 4x − 3 = 2x + 6
  3. | − 2x → 2x − 3 = 6, | + 3 → 2x = 9, | : 2
  4. x = 4,5

G8: Gleichung aus der Geometrie

Ein Rechteck ist doppelt so lang wie breit. Sein Umfang ist 27 cm. Wie lang sind die Seiten?

  1. Breite = x, Länge = 2x
  2. Umfang: 2 · (2x + x) = 27 → 6x = 27
  3. | : 6 → x = 4,5 cm (Breite), Länge = 9 cm
  4. Probe: 2 · (9 + 4,5) = 27 ✓

G9: Winkel im Dreieck

Im Dreieck ist β doppelt so gross wie α, und γ ist 20° grösser als α. Berechne alle Winkel.

  1. α = x, β = 2x, γ = x + 20°
  2. Winkelsumme: x + 2x + x + 20 = 180
  3. 4x + 20 = 180  | − 20 → 4x = 160  | : 4
  4. α = 40°, β = 80°, γ = 60° (Probe: 40 + 80 + 60 = 180 ✓)

Tipps für die Prüfung

  • Vereinfachen: Gleichartige Terme mit Farbstiften markieren (z. B. x³ rot, x² blau). Dann vergisst man keinen Term und kein Vorzeichen.
  • Resultat ordnen: Den höchsten Exponenten zuerst schreiben (3x³ + 6x², nicht 6x² + 3x³). Beides ist richtig, aber geordnet ist übersichtlicher.
  • Gleichungen: Jeden Schritt rechts mit | notieren (| + 12, | : 5). So sieht man, was man getan hat.
  • Immer die Probe machen: Lösung in die Gleichung einsetzen. Beide Seiten müssen gleich sein.
  • Auf die Form achten: Wird ein «Dezimalbruch» verlangt, die Lösung als Dezimalzahl schreiben (7,8 statt 39/5).
